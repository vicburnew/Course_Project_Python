# Приложение для анализа банковских операций

## Краткое описание 
Данное приложение предназначено для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы. 

## Установка и использование
1. Клонируйте репозиторий:
```
https://github.com/vicburnew/Course_Project_Python.git
```
2. Установите зависимости:
```
poetry install 
```
3. Запустите модуль main.py из корневой директории проекта 
```
python main.py
```



## Примеры использования 
В проекте реализовано несколько функций, 
расположенных в пакете .src. Вызов функций реализован из 
модуля main.py. Для тестирования модулей используется пакет pytest. 
Широко применяются фикстуры и параметризация.

### Описание работы функций

1. Функция read_excel_file()   
    *Функция принимает на вход путь к excel-файлу 'transactions_excel.xlsx' и
    возвращает список словарей с данными о финансовых транзакциях.
    Если файл пустой, содержит не список или не найден,
    функция возвращает пустой список.*    
10. Декоратор @log  
    *Декоратор, который автоматически логирует начало и конец выполнения функции,
    а также ее результаты или возникшие ошибки. Принимает необязательный аргумент
    filename, который определяет, куда будут записываться логи (в файл или в консоль).
    Если filename задан, логи записываются в указанный файл.
    Если filename не задан, логи выводятся в консоль
    Логирование включает:  
    Имя функции и результат выполнения при успешной операции.  
    Имя функции, тип возникшей ошибки и входные параметры,
    если выполнение функции привело к ошибке.*  


11. Функция read_json_file()
    *Функция принимает на вход путь до JSON-файла и
    возвращает список словарей с данными о финансовых транзакциях.
    Если файл пустой, содержит не список или не найден,
    функция возвращает пустой список*   


12. Функция convert_currency_to_rub()  
    *Функция принимает на вход транзакцию и возвращает сумму транзакции
    (amount) в рублях, тип данных — float. Если транзакция была в USD или EUR,
    происходит обращение к внешнему API для получения текущего курса валют
    и конвертации суммы операции в рубли.
    Для конвертации валюты используется Exchange Rates Data API*   


15. Функция user_welcome_input()   
    *Функция приветствия в начале программы и обработки выбора источника
    данных - JSON, CSV или XLSX файл*   


16. Функция user_status_input()   
    *Функция, с помощью которой пользователь выбирает статус интересующих его
    операций - EXECUTED, CANCELED, PENDING*   


17. Функция user_input_fbd()   
    *Функция, с помощью которой программа выводит уточняющий
    вопрос для выборки операций, необходимых пользователю,
    ('fbd' =  "filter by date")*   


18. Функция user_input_sbda()   
    *Функция, с помощью которой программа выводит уточняющий
    вопрос для выборки операций, необходимых пользователю
    ('sbda' = "sort by date ascending")*   


19. Функция user_input_rf()   
    *Функция, с помощью которой программа выводит уточняющий
    вопрос для выборки операций, необходимых пользователю
    ('rf' = "ruble filter")*   


20. Функция user_input_sw()   
    *Функция, с помощью которой программа выводит уточняющий
    вопрос для выборки операций, необходимых пользователю
    ('sw' = "specific word")*   


21. Функция filter_by_description()   
    *Функция принимает на вход список словарей с данными о банковских
    операциях и строку поиска, а возвращает список словарей,
    у которых в описании есть данная строка.*   


22. Функция count_operations_by_type()   
    *Функция принимает на вход список словарей с данными о
    банковских операциях и список категорий операций, и возвращает словарь,
    в котором ключи — это названия категорий, а значения —
    это количество операций в каждой категории*  


23. Функция program_output_1()   
    *Функция вывода результатов работы программы в консоль (JSON)*   


24. Функция program_output_2()   
    *Функция вывода результатов работы программы в консоль (CSV и EXCEL)*   

 


### Тестирование

В проекте написаны тестовые функции для контроля правильности кода
при различных значениях входных параметров с использованием фикстур и параметризации, а также "заглушек" Mock и patch. 
Результаты с отчетом покрытия тестами в формате HTML хранятся в репозитории проекта в папке /htmlcov.  
Для анализа покрытия кода нужно в любом браузере открыть файл index.html.
